# Haoran Xu — Academic Personal Website

A warm editorial personal website built on the official [al-folio](https://github.com/alshedivat/al-folio) Jekyll starter.

- About: confirmed identity, Control Science and Engineering at Zhejiang University, real photograph with CSS cropping, and verified GitHub profile
- Research: understanding and designing learning, with a continuous generative line study and keyboard-accessible perspective switching
- Reflections: the first complete author-provided bilingual essay, On Living, with paragraph-preserving language switching and refined long-form reading
- Self-hosted Source Serif 4 and DM Sans, light/dark themes, responsive layouts, and reduced-motion support
- Pure static output with GitHub Actions deployment to https://haoranxu-research.github.io/
- Publications, CV, and Projects source files preserved but excluded from current output

Local preview: http://localhost:4000/

See [design notes](docs/EDITORIAL.md), [deployment instructions](DEPLOYMENT.md), [file changes](CHANGELOG-SITE.md), and [validation results](VALIDATION.md).

Browser verification: `node scripts/check_editorial.cjs` and `node scripts/check_reflections.cjs`. Article screenshots are saved to `preview/on-living/`. See [bilingual writing structure](docs/REFLECTIONS.md) to add future essays.

Original al-folio MIT license and font SIL licenses are retained. Local CV drafts and working materials remain private and excluded from publication.
